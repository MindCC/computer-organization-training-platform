## 温暖街角

```text
Use case: ui-mockup / original narrative game concept.
Create one realistic production-quality desktop narrative game screen, target 1440 x 1024, no browser chrome, no device frame, natural composition. Date anchor 2026-10-03; show fictional game day “第1天 · 上午”, no real-calendar dates needed.
Game: 《芯游记：街角装机店》, shop named “芯邻装机”. Player runs a neighborhood PC assembly shop. This is the first customer's reception scene, not a management dashboard. A detailed environment and appealing original adult character design must be visible. Focus primary action: ask customer about her computer use. Only two supporting conversation choices.
Original customer Xiaolin 小林, 27-year-old Chinese woman, shoulder-length black hair, ivory shirt and mint-teal knitted vest, canvas document tote, calm but a little worried, credible everyday proportions, no school uniform. Mentor 老赵, 58-year-old Chinese man, gray short hair, thin framed glasses, navy workshop coat and rolled sleeves, subtle in background if composition allows.
Reference image 1 is existing functional 3D workbench and real hardware shapes/color language; image 2 is current dialogue UI structure. References are grounding, not edit targets. Preserve the recognizable navy anti-static workbench, monitor, keyboard, realistic upright PC beside desk, stocked PC component boxes, light neutral shop walls and teal interaction states. Build a broader original shop scene around these. Existing real interactive 3D assembly is still accessed by clicking the workbench; no automatic assembly, no replacing hardware models with photos.
Upper compact game header shop name and game day only, unobtrusive sound/settings symbols. Generous shop scene covering most of screen. Customer conversation remains co-located with customer. Bottom clear readable Chinese dialogue and three actual choices, typography appropriate for 1440 x 1024. Exact key text: “芯邻装机” ; “第1天 · 上午” ; “小林” ; “明天要做汇报，旧电脑打开资料总卡。你能帮我看看吗？” ; primary “平时主要开什么软件？” ; secondary “资料大概有多少？” and “预算准备了多少？” ; small environment hotspot “装机工作台”. Keep displayed copy short, no invented numeric stats, no sales chart, no navigation tabs, no rows of metric cards. Use scene, portrait, dialogue as clear hierarchy. Not a poster or multi-panel moodboard; one coherent playable game screen. All character/environment artwork original, no copied IP.
Direction name (internal, don't print): 温暖街角. Art direction: richly detailed warm hand-painted narrative adventure with clean contemporary illustration, subtle paper texture, afternoon pale sunlight, beautiful light wood shelves against cream walls, navy workbench and mint accents. Eye-level camera from inside the entrance toward reception. Xiaolin's expressive half-body portrait foreground left at the reception counter; her tote set on counter. Back right shows the recognizably functional PC assembly desk, parts pegboard and upright computer, left windows opening onto quiet neighborhood. Large environment, dialogue dock across bottom as a single ivory surface, character name clearly above dialogue, primary option teal-filled and supporting choices understated. Cinematic but bright, believable shop clutter, no anime fantasy effects. Customer illustration feels alive and approachable. Intentional composition and comfortable negative space.
```
