# 教师装机练习看板

用户要求继续修改、完成后推送。沿用上次列出的第 2 项：教师查看服务端已同步的装机练习。

- 入口：教师工作区 → 学情统计 → 装机练习。
- 展示当前班级全部学生，包括暂无记录者；按姓名/学号、未完成/已完成/暂无记录筛选。
- 指标基于每学生每订单最近保留的 20 次完成记录：完成次数、平均练习分、完成用时、错误及提示次数；未完成练习单独计数。
- 单次复盘按学生展开，展示模式、订单、时间、错误、提示和建议；错误排行仅根据保留的错误明细（每轮最多 20 条）。
- GET 班级汇总和学生详情均要求教师登录、拥有班级和当前学生成员关系。服务端仅投影所需字段，不返回完整装配草稿；不写正式成绩。
- 只在当前页签挂载，45 秒可见性刷新，支持手动刷新和失败重试；切换班级销毁旧数据及待响应回调。
- 验证：真实 HTTP 权限/统计/损坏数据、生产教师看板及新增复盘/筛选/切班/错误重试/移动布局；构建与包预算。
