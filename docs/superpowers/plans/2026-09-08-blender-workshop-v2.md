# Blender 装机工作台 v2 实施与验收

用户已批准 2026-09-08 六项完善并要求一次完成。延续 Precision Workshop、现有评分、学生/订单草稿隔离和重载后重新自检要求。

## 交付顺序

1. 资产规范 v2：以模型安装锚点完整变换为准；接口、相机观察点、可动节点使用稳定名称及 glTF extras。独立导出读取精修 .blend，生成有 SHA-256 版本的 GLB 清单；生成基础模型需显式输出路径，避免覆盖精修文件。
2. Blender 精修：结构比例/接触面、防呆接口、丝印贴图、独立 CPU 压杆/DIMM 卡扣/风扇转子，安装与开机动画；保持低面数和有限材质。
3. Three.js 资产适配：完整安装矩阵、独立材质高亮、低成本环境反射、可动节点、接口随模型运动及资源清理；模型失效仍可使用已有辅助流程。
4. 交互：场景点击线缆端和接口、匹配/错误高亮与连接预览，保留下拉框辅助；3D 插槽命中与方向限制，取消/错误释放不安装。
5. 观察和布局：根据部件/接口包围盒定位近景，专注模式把主要空间交给场景，避免标签/提示遮挡主要目标；考虑 1366×768 与窄屏。
6. 验收并提交：相关单元测试、真实 GLB 节点/姿态/面数/贴图/可动部件检查、构建/资产预算、生产 3D 交互与降级回归、十次场景生命周期和帧率；截图复查，更新资产规范，提交所有完成工作。

## 边界与实现选择

- Blender 负责几何、材质、节点和动作素材；React/纯函数负责安装、连接和开机状态，不信任动画完成作为评分依据。
- 本轮不引入软体线缆或螺钉物理，不使用外部品牌或游戏资产。
- 保持当前场景单位兼容，在模型适配边界统一转换米制。安装参考点采用父子完整矩阵，包含旋转；可动子件使用独立局部原点。
- 程序化替代操作保留；v2 模型校验包含接口和可动节点，避免静默缺失。
- 不因新贴图引入额外解码器，先采用小型内嵌 PNG；新增渲染依赖必须计入既有 3D 包预算。

## 完成标准

- 手工保存源模型后可独立导出，无须运行重建脚本；导出结果能准确预览并能识别资源版本。
- 部件安装位置/方向、线缆两端和观察点由资产驱动；接口移动后无需更改线缆硬编码端点。
- CPU 压杆、DIMM 卡扣与开机风扇有明确可见变化，减少动态效果时直接进入稳定姿态。
- 鼠标可从场景连接所有五条线，错接、缺失端点和关闭侧板受现有业务规则约束。
- 近景可辨认接口；1366×768 专注视图的场景占据主要空间，移动端无横向溢出。
- 生产加载、拖放、接线、拆卸、重载隔离、模型失败/WebGL 不可用流程通过，性能预算保持可用并记录本机测量限制。
