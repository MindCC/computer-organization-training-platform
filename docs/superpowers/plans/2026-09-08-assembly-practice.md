# 3D 装机教学练习

用户批准继续完成引导、独立和故障三类练习。沿用现有工作台，不改变客户订单评分或服务端提交。

## 实现

1. 新增独立练习入口，练习使用自己的配置和内存草稿，返回订单恢复原有订单草稿。练习会话不跨刷新恢复成功状态。
2. 引导模式按实际状态给出下一步、位置和原因；独立模式隐藏匹配颜色/预览及自动答案，保留有名称的接口和可选择目标的辅助安装。
3. 三个故障工单：CPU 供电缺失、散热器缺失、SATA 数据缺失。使用真实装配状态生成故障，允许尝试自检并给出症状；学生修复后必须实际完成开机。
4. 记录失败操作、主动提示次数、完成耗时和复盘建议。练习分只用于本次训练，不调用订单提交或持久化正式成绩。
5. 验证模式隔离、故障修复前后、核显/独显、提示与错误计分、完整生产练习和原有 3D 回归。保留模型/包预算与课堂性能检查。

## 验收

三种练习可开始、操作、求助、完成和重练；错误不会被算作成功。离开练习不改变原订单配置/草稿，页面刷新不能获得成功记录。1366×768 与窄屏可访问练习及复盘，3D 为主要操作区域。
