# 装机练习历史与恢复

用户已确认将既有 main 推送到 Gitee，然后实现第 2 项：按学生保存练习历史，刷新恢复未完成练习。

## 范围

- 在现有浏览器 localStorage 中按学生与订单隔离，使用独立练习命名空间；不修改订单草稿或正式成绩，不增加跨设备同步。
- 原子保存未完成练习的模式/工单、硬件配置、已装部件、结构/线缆、错误/提示记录及累计用时。恢复后清除开机完成状态，要求重新自检；离线时间不累计到恢复后的练习用时。
- 完成结果独立保存最近 20 条历史，使用稳定会话 ID 去重。查看历史不会恢复成功装配或影响当前练习。
- 切换模式、工单和重新练习仍创建新一轮；完成历史保留。存储不可用时继续内存练习并明确提示保存失败。
- 保存时及恢复时验证数据版本、配置、记录形状；异常数据回退为新练习，不能伪造当前开机状态。

## 验收

单元测试覆盖身份隔离、损坏/未知版本、配额失败、恢复重新自检、记录去重/保留上限和离线计时。生产浏览器覆盖未完成练习跨刷新恢复、故障/配置/扣分保留、完成历史跨刷新、重练保留历史及订单草稿不变；运行相关生产回归、预算及练习生命周期检查。
