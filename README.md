# 芯游记 ChipQuest · 计算机组成原理实训平台

面向高校《计算机组成原理》课程的教学与实训平台，覆盖教材八章。教师编排并发布课堂任务，学生沿任务主线完成演示、练习和实训；系统记录学习证据，AI 提供解释与辅导建议，教师审核后安排针对性补练，再用测验和复测检查学习结果。

技术栈：React 19 + Vite 6 + Express 5 + better-sqlite3（SQLite）+ React Flow + 原生 Three.js + GSAP。

## 导航与教学主线

学生的一级导航依次为 **课程首页 → 实训平台 → 课程学习 → AI助教 → 学习复盘**；教师另有 **教师看板**。

| 一级入口 | 主要内容 |
| --- | --- |
| 课程首页 | 当前课堂任务、课程路线、今日补学 |
| 实训平台 | 硬件互动装机、八章实验及个人完成情况 |
| 课程学习 | AI讲演、互动演示、课后作业；教师对应入口为题库试练 |
| AI助教 | 独立课程聊天页、章节选择、个人对话历史、学习火花和默契值 |
| 学习复盘 | 学习记录、错题本、知识库 |
| 教师看板 | 任务库、题库出卷、作业管理、课堂执行、教学活动、学情统计、班级管理 |

课程学习和学习复盘点击后在下一行展开二级导航；当前功能保持高亮，支持键盘操作和 Escape 收起。教师工作台与助教工具使用各自的局部侧栏。导航、实训及聊天布局详见[功能与验证记录](prototype/docs/primary-navigation-2026-10-12.md)。

### 师生机协同

1. **教师准备**：从任务库选用预设模板、手动编排或通过 AI 生成草稿，审核学习目标、题目和完成条件后发布。
2. **学生执行**：接受任务，按节点依次完成诊断、教师演示、独立操作、课程答疑、检验与反思。
3. **系统反馈**：汇总各任务链及单个节点的完成度、答题和实验记录，提供可追溯的学情依据。
4. **教师调整**：结合学情与 AI 建议审核并发布个性化补练，保留教师的教学决策和评价环节。
5. **学生复测**：完成补练与复测，记录订正和后续表现，再更新下一轮学习安排。

任务链与辅导流程可应用于不同章节；预设模板仍需教师结合班级目标确认。详见[任务库与工作流](prototype/docs/task-library-workflow-2026-10-05.md)、[课堂任务链](prototype/docs/classroom-task-chain-2026-10-05.md)和[课程教学闭环](prototype/docs/course-teaching-loop-2026-10-05.md)。

## 功能总览

### 学生端

- **课程路线与任务主线**：按教材八章组织课程、课堂任务和实验，任务卡显示目标、预估耗时与尝试次数。未解锁实验可进入练习；默认须完成前置关卡才能提交后续实验，教师可设置跳关。
- **今日补学**：依据自己的提问、错题和实验线索推荐最多三项后续学习，支持诊断 → 公开知识讲解 → 练习 → 不同题号复测、进度恢复及推荐反馈。题量不足会明确提示，不将打开资料或反复做同一题视为掌握。详见[个性化补学](prototype/docs/personal-study-recommendations-2026-10-09.md)。
- **电路实验工作台**：PhET 式沉浸式布局，拖拽连线搭建电路，实时数据流检测、自动评分、分级提示，支持 Undo/Redo
- **3D 计算机拆解**：原生 Three.js 整机探索、分步装配、部件拖动与归位、X-ray 和总线可视化。
- **装机店剧情与硬件挑战**：接待剧情顾客（立绘 + 对话），在预算、性能、满意度之间做真实取舍完成装机报价；还支持整机瓶颈诊断与定向升级（基线测试 → 证据诊断 → 3D 更换硬件 → 复测 → 服务回执），性能数字明确标注为教学仿真
- **章节互动演示**：八章对应的十个演示页，包含补码、运算基础、运算器、存储器、寻址、CPU、总线与输入输出。逐题提交保存原始答案、参考答案与解释，错题进入统一错题本；可见且活跃的学习时间计入学习记录，后台页面与长时间无操作不计入。含 CPU 执行时间、Cache AMAT、总线带宽等参数探索实验。
- **错题本**：聚合实验、章节练习、演示测验、课后作业及拍照导入等来源，支持回到原题巩固。纸面错题经视觉模型切题后由学生核对、归档；讲解优先搜索本账号知识文档及可用题库，命中时标注本地来源，否则可明确选择 AI 讲错因与同类题练习。支持连续两轮全对标记「已掌握」、手动修正和复习卷打印。配置见 [环境变量示例](prototype/.env.example)，回归入口为 `npm run qa:mistake-photo`。
- **小芯 AI 助教**：独立聊天页提供宽屏对话、底部输入框和侧栏历史，支持连续展示问答、查看历史及开始新对话。课程讲演、练习与装机/电路工作台也能就近答疑，结合当前公开课程上下文；操作快照和既往课程问题须本次明确选取。AI 未配置或暂不可用时明确显示本地参考来源，保留课程范围检查与账号隔离。GKK 讲演旁的答疑只依据课程目录与明确提供的文字，不推测播放进度或当前幻灯片。详见[讲演答疑](prototype/docs/lecture-qa-2026-10-08.md)。
- **学习火花与小芯默契值**：按有效学习证据记录每日火花和参与情况，纯聊天、登录或停留不加分，也不自动改变课程成绩。教师可设班级期间、目标与加分上限并审核确认；每次答疑仅明确选取的最多三条既往课程问题可用于衔接讲解。详见[规则与边界](prototype/docs/companion-engagement-2026-10-09.md)。
- **实验证据诊断与补练**：全加器支持服务器复算、四级提示、修正验证、变式复测与账号恢复；教师可审核课程依据、发布补练、回看结果并导出试用记录。明确选择后才向 DeepSeek 发送本次结构化检测片段；详见 [首期说明](prototype/docs/learning-coach-2026-10-05.md)。
- **知识库与思维画板**：学生和教师可导入课程文档、全文检索，并从文字或图片生成可编辑导图；支持重绘优化、节点与关系箭头编辑、账号保存、草稿恢复和 PNG/SVG 导出。文字默认复用 DeepSeek，图片识别需配置视觉模型，见 [配置与验证说明](prototype/docs/mind-map-board-2026-10-04.md)。
- **学习记录**：按学习概览、计划与专注、详细记录分区；含六张统计图、可展开的日历/热力图与分来源记录，小芯给出复习建议。课程知识图谱位于知识库，冒险地图位于课程首页
- **学习计划与番茄钟**：在学习记录安排实验、章节、教师补练或作业；实验台可就近计时。账号保存暂停与恢复状态，结束记录成果/疑问，休息单独统计。真实完成证据与个人确认分别标注，教师查看他人记录不访问私人计划。验收：`cd prototype` 后运行 `npm run qa:study-planning`。
- **课后作业与 AI讲演**：作业提交、客观题判分、教师反馈；按章选择讲演，支持独立播放页、全屏与本课答疑。
- **个人设置**：资料、提示模式、密码强度提示与修改（单表单一次保存）
- **刷新不丢进度**：当前页面与所在关卡记在本标签页的 `sessionStorage`，刷新后回到原处；同一台电脑换人登录会自动清空

### 教师端

教师可使用课程首页、实训平台、课程学习、AI助教和学习复盘，以「教师试练」身份体验并独立保存个人数据。教学管理统一进入「教师看板」；题库出卷与作业管理位于教学工作台侧栏。

- **班级管理**：创建班级、CSV 导入与逐行错误反馈、新账号初始口令下载、重置密码、停用/启用/转班、归档及跳关设置。连续补导保留本页生成的口令。回归入口为 `npm run qa:class-management`。

- **学情概览看板**：班级完成率、平均分、高频错误、硬件挑战瓶颈，以及任务链和单节点学情；提供可追溯记录与教学建议。
- **学生详情**：学习概览、逐关最佳成绩、最近提交、高频错误画像、笔记与反思
- **智能助教**：DeepSeek 生成课堂行动建议（本地规则降级兜底）
- **学习回顾（教师学情复盘）**：按班级/学生查看真实学习记录与错题本，附全班学情分析（章节进度、高频错误归因、建议关注的学生、下一步教学建议）；教师还可用「我的教师试练」亲自体验关卡，试练数据单独保存、不污染学生数据
- **任务库与任务链**：创建、查看、修改、删除和发布教学任务；支持 AI 草稿、预设模板、工作流节点拖动编排、自定义节点、每步目标与完成条件。教师可预览和演示实际任务，演示试答与学生进度分开。课堂支持开课、暂停/恢复、结束与回顾，提交具有幂等保护。
- **课程工作台**：教师审核并发布课程、分配项目小组、集中评价学生里程碑；学生可提交和修改未评价的个人反思
- **作业管理**：草稿 → 出题 → 发布到班级 → 学生提交 → 判分/教师反馈。可从内置或教师私有题库筛选、全选并批量添加题目，也可手工出题；支持客观题自动判分与简答人工批改。
- **题库与自动出卷**：教师私有题库（单选/判断/填空/简答），支持手工录入、JSON/CSV 批量导入（幂等去重）、一键导入内置章节题库、从知识库文档 AI 出题（候选题自动校验、勾选入库）；按章节范围与题型数量自动组卷（随机种子可复现），预览后可存为作业草稿或直接发布到班级，客观题自动判分
- **数据导出**：单科 CSV、完整成绩包（archive.zip，含成绩/提交/笔记/硬件/班级汇总）、数据库备份
- **审计日志**：登录、导入、导出、备份等关键操作留痕，可按类型与时间筛选

## 快速开始

在仓库根目录打开终端，执行以下命令。依赖版本以锁文件为准。

```bash
cd prototype
npm ci
npm run seed:teacher   # 创建教师账号（默认 teacher / ChangeMe123!，可用 TEACHER_PASSWORD 覆盖）
```

启动两个服务（API 在前，Vite 代理 `/api` 到它）：

```bash
# 终端 1：Express API（端口 8787）
npm run server

# 终端 2：Vite dev（端口 5173）
npm run dev
```

打开 [本地开发页面](http://127.0.0.1:5173/)。使用教师账号创建班级、导入学生，再通过学生入口登录。

### 演示与配置

- 服务启动时幂等准备演示身份；演示教师默认 `demo-teacher / Demo123!`，可只读查看获授权班级；演示学生可接受任务、提交练习和作业。已有账号被管理员修改的口令不会在普通启动时覆盖。
- 一键演示登录由 `ENABLE_DEMO_LOGIN=1` 控制。可将 `prototype/.env.example` 复制为 `prototype/.env` 后按需配置；`npm run server` 通过 Node 的 `--env-file-if-exists=.env` 读取它。
- 如需第二个合成学情演示班，在配置好目标 `DATABASE_PATH` 后执行 `npm run seed:demo2`；它生成 24 名合成学生与分层实验、测验、答疑和作业记录。正式教学数据不要作为演示样本提交到仓库。
- `seed:teacher`、`seed:demo2` 等独立脚本从进程环境读取配置；使用自定义数据库时应同时为播种与服务启动指定相同的 `DATABASE_PATH`。
- 当前 `npm run seed:demo` 是旧合成演示数据清理与演示身份准备入口，**不是生成旧版 40 人演示学情的命令**；如需运行，先确认目标数据库并做好备份。

## 部署

生产构建位于 `prototype/dist/`，由 Express 托管；生产模式需要显式配置会话密钥、数据库路径与公开访问地址。首次 Linux 部署见[部署指南](deploy/README.md)。

已安装的 Linux/systemd 服务可在服务器上更新：

```bash
cd /opt/zcyl
sudo REMOTE=origin bash deploy/update.sh
```

`origin` 应为服务器上已配置认证的目标仓库；若使用其他远端，替换为相应远端名。更新脚本检查未提交修改和分支关系，在线备份 SQLite 与旧前端，再安装依赖、构建、迁移、重启并核对健康接口中的发布版本。保留既有服务与 AI 环境配置；凭据由服务器 Git 配置管理。

SQLite 使用 WAL 模式，备份应使用平台的在线一致性备份或更新脚本的备份机制，不直接复制运行中的主数据库文件。GitHub/Gitee 代码同步与服务器部署分别执行，以实际运行服务的版本为准。

- 部署与回滚：[课堂运行手册](docs/classroom-deployment.md)
- 长期规划：[课堂平台规划](docs/classroom-long-term-prd.md)
- Cookie 安全：`HttpOnly + SameSite=Lax`，HTTPS 下设置 `COOKIE_SECURE=1` 启用 `Secure`

### 环境变量

`prototype/.env.example` 中有完整示例（含注释）。核心变量：

| 变量 | 必填 | 说明 |
|------|------|------|
| `SESSION_SECRET` | 生产必填 | 会话签名密钥；生产模式缺失或使用默认值时拒绝启动 |
| `DEEPSEEK_API_KEY` | 否 | 默认课程答疑/教学建议服务配置；对应能力未配置时提供本地参考 |
| `STUDY_ASSISTANT_API_KEY` / `STUDY_ASSISTANT_BASE_URL` / `STUDY_ASSISTANT_MODEL` | 否 | 小芯课程答疑的独立提供商配置 |
| `MINDMAP_VISION_*` | 否 | 图片转导图等视觉识别配置，文字导图可使用默认模型 |
| `MISTAKE_VISION_*` | 否 | 拍照错题识别配置，未独立配置时可复用导图视觉配置 |
| `DATABASE_PATH` | 否 | SQLite 路径（默认 `data/classroom.sqlite`） |
| `PORT` | 否 | 服务端口（默认 8787） |
| `COOKIE_SECURE` | 否 | HTTPS 部署置 `1`（或 `true`），为 cookie 加 Secure 标记 |
| `PUBLIC_BASE_URL` | 否 | 前端外部地址，用于 CSRF Origin 校验；HTTPS 反代部署时必填 |
| `TRUST_PROXY` | 否 | 反向代理后面部署时置 `1`，信任 `X-Forwarded-For`；**直接对外暴露时必须留空**，否则可伪造成源 IP 绕过按 IP 的登录限流 |
| `TRUST_PROXY_HOPS` | 否 | 反向代理层数（默认 1） |
| `TEACHER_USERNAME` / `TEACHER_PASSWORD` / `TEACHER_NAME` | 否 | 首次 `npm run seed:teacher` 的教师账号 |

> `npm run server` 读取 `prototype/.env`；`npm run dev:server` 和其他独立脚本使用进程环境。生产部署由 systemd 环境文件注入。配置示例中的提供商地址与模型仅为示例，须按实际服务填写；未配置视觉服务时无法执行图片识别。真实密钥、数据库、学生名单、口令导出与备份不提交到 Git。

### 学生账号与初始口令

- CSV 导入时若**未提供初始密码列**，服务端为每个新账号生成一次性随机口令，并在导入结果中返回；教师端「课堂设置 → 学生导入」会列出这些口令并提供「下载初始口令 CSV」，请在导入后立即发放。
- 教师未显式指定新密码时，重置密码同样由服务端生成随机口令并回显给教师。
- **首次改密是自愿的**：平台不会用强制改密闸门阻断登录或课程访问，学生可随时在「个人设置」里自行修改密码（账号会被标记建议改密）。
- 同一名学生可以同时加入多位教师的班级；导入不会改写他班学生已有的资料，也不会复活被停用的账号。

### AI讲演

「AI讲演」是学生与教师共用的课程入口。页面按章展示已配置的讲演，选择主题后进入独立播放页，单次只加载一个讲演播放器；播放器保持 16:9 比例并支持全屏。此页面不提供 PPT/PPTX 上传。

### 安全相关行为（部署前请知悉）

- **登录限流**：按用户名（5 次/分钟）与来源 IP（30 次/分钟）双维度拦截；任一命中返回 429。成功登录会同时清除两个维度，避免共享出口 IP 的教室被个别学生输错密码拖垮。
- **改密后吊销其他会话**：`/api/auth/change-password` 会踢掉该账号的其它设备会话，仅保留当前会话。
- **整库备份需二次确认**：`POST /api/admin/backup` 需要请求体里带上**本人当前口令**（`{"password":"..."}`），教师端「数据与备份」区块内置了输入框。快照为原始 `.sqlite` 文件，可直接用于恢复；GET 方式已移除。
- **智能助教不发送学生身份**：发往 DeepSeek 的载荷中，学生只用代号（`学生1`、`学生2`…），不含姓名与学号；AI 返回的代号会在服务端映射回真实姓名，教师界面显示不变。本地规则降级不走网络，因此仍使用真实姓名。
- **个人答疑与学习记忆**：课程问题、明确选取的操作快照或最多三条既往课程问题只在相应操作时发送。学习计划、完整历史、私有文档及身份信息不会作为自动附加上下文；历史查看和教师试练遵守账号/班级权限。
