# 计算机发展史六阶段图

本套为六张独立横版 PNG，统一采用 Blender Cycles 写实渲染视觉风格，由内置 image_gen 生成；不包含 Blender 模型文件。

采用两类机械/机电先驱与经典四代电子计算机的教学结构。图中年份指具体机型的历史节点，不是各阶段统一的起止界线。微处理器阶段从20世纪70年代兴起并延续至今，IBM PC 5150 是其个人计算机普及的重要代表，1981年不是微处理器的诞生年份。

## 准确性说明

阶段技术、代表机型和所标年份已依据上述资料核对。图像属于历史复原示意：构图、材质与局部器件由AI生成，不能保证每个开关、键帽、齿轮及内部线路与馆藏实物一一对应，也不作为工程结构图使用。代表机型的选择是教学取舍，并不存在各阶段唯一的“最具代表性”机型。

Z3 最终版修正了首版出现的发光数字读出与纸带表现，改为灯泡指示和穿孔胶片示意。正式交付仅收录修正版。
