# 平台完整性与体验审核 · 2026-10-04

## 范围

从访客、学生和教师的实际操作路径检查登录、首页、学习记录、实验工作台、装机店、题库、教师作业、错题本、知识库、课件、演示及课堂管理。沿用已有浅色工坊设计、章节顺序、参与型计分和真实 3D，不重置现有账户或学习数据。

## 本次修正

| 模块 | 问题与处理 |
| --- | --- |
| 登录与同步 | 服务连接失败提供重连入口；业务数据加载失败保留有效登录，分别恢复成功部分，显示可重试的同步提示。退出请求失败保留真实身份，401 可以清理失效登录。 |
| 数据隔离 | 旧账号的学习数据请求、旧班级的课堂请求不能覆盖当前页面；账户切换清理前端业务状态，课堂视图按账号/班级作用域展示。 |
| 统一导航 | 浏览器前进和后退恢复实际模块；历史记录不能恢复另一账号的身份；九个演示入口使用系统顶栏和返回路径。 |
| 帮助与提醒 | 帮助有实际使用指南；通知读取真实课堂、待提交作业和待巩固错题，移除固定假数字。支持 Escape、焦点恢复和窄屏布局。 |
| 首页与学情 | 最近资料读取真实知识库记录；移除虚构历史活动；复习入口根据当前课程进度选择关卡，保留真实植物学习树。 |
| 题库与错题本 | 按章练习在服务器判分并按账户同步，统一实验、题库和作业错题，支持指定题目重练、订正状态和原作业回看。教师作业订正不覆盖原成绩。 |
| 学生作业 | 读取与保存显示状态及错误，输入按账号和作业保存本机草稿；刷新可恢复，服务端保存失败保留答案，提交过程禁止重复点击。 |
| 教师作业 | 加载失败可重试；切换详情防止旧响应覆盖；创建、添加题目、发布、批改有处理中与失败反馈。创建失败保留表单内容。 |
| 教师学情 | 章节明细和分组按钮展开真实学生学习证据；零次尝试不算进入实验，同一学生重复错误不重复计为多名学生；证据区可滚动查看。 |
| 课堂管理 | 切换班级立即隔离原课堂；开课、暂停、恢复和结束保留原生命周期及幂等提交。课堂操作失败显示可重试反馈，避免未捕获异常和重复操作。 |
| 课件 | 文件渲染、课件列表及分页笔记失败均可重试；笔记读取忽略过期响应；草稿按文件和页码保留，保存失败不清空内容。 |
| 知识库 | Obsidian 风格的工具栏、左侧文件列表和主阅读区，保留真实上传、分析、原文、全文搜索和删除索引联动；窄屏可展开侧栏。 |
| 装机店 | 阿宁恢复人物图片和店铺互动接待，沿用真实配置、3D 安装、自检、服务器交付回执与下一位客户流程。 |
| 响应式与加载 | 修复章节标签在平板宽度撑宽作业页面的问题，手机表单重排；登录、帮助等按需加载，主入口保持在预算内。 |

## 验收方法

生产构建后使用独立临时 SQLite 数据库、真实 API 和单个 Edge 浏览器依次验证，不使用正式账户的数据造测试样本。异常检查主动注入 503、断网或延迟响应，随后撤销注入，确认真实服务恢复。主要页面检查 1366、768、390、320 像素宽度，教师工作台检查 1366、768、390 像素。
