# 首页检查与优化 · 2026-10-03

## 设计目标

让学生快速找到当前任务和章节实验，统一现有浅色工作台、青绿色操作与真实工坊的视觉语言。保留八章课程、36项实验、独立演示、学习记录和课堂入口。

## 检查与修改

| 步骤 | 修改前发现 | 修改后 |
| --- | --- | --- |
| 1. 首页首屏 | 透明面板压在照片上，白色标题/说明与亮背景混杂；任务和状态层级混乱 | 浅灰底、实体白色任务面板，青绿色任务边线和主按钮；工坊图片独立放置；右侧集中进度 |
| 2. 展开章节 | 页面下方白字落在浅底上；长标题与说明被省略；进度信息难辨认 | 深色标题和说明，正文可换行；章节节点、连接线与真实进度条；明确完成/继续/练习状态 |
| 3. 首次学习 | 引导与核心任务争抢首屏，空平均分显示为0分 | 当前任务先展示，引导变为紧凑辅助区；无计分成绩显示“暂无成绩” |
| 4. 窄屏 | 内容密集，多列结构不适合窄屏阅读 | 任务与进度改为单列，章节说明/状态重新排列；保留自然滚动和清楚的操作入口 |
| 5. 课堂首页 | 深色课堂横幅与平台浅色基调不一致 | 浅色课堂任务栏、清晰阶段/时间、青绿色进入按钮；锁定关卡标注可练习 |

## 已验证

- 独立Edge生产浏览器：1366、1093、768、390、320像素宽，无横向溢出，当前任务入口可见。
- 对实际渲染文本计算对比度，普通文字至少4.5:1，大号文字至少3:1；检查展开章节和首次学习状态。此检查不是完整无障碍认证。
- 八章键盘折叠/展开、36项实验和八个演示入口；寻址演示新标签打开并显示已连接学情，新增偶校验关卡可进入。
- 游客引导、跳过引导和刷新后保留关闭状态；开始实验正确引导游客登录。
- 全部完成状态用浏览器学情响应夹具验证，展示完成提示且保留章节复盘；该夹具未写入服务端成绩。
- 完整生产课堂流程继续通过：开课、进入、四阶段提交、暂停/恢复、结束与报告，零pageerror。
- 构建和性能预算通过：入口509319 B / 512000 B；增量3D gzip198800 B / 225280 B。

证据位于`qa-artifacts/`：`home-before-desktop.png`、`home-after-1366.png`、`home-after-320.png`、`home-after-first-use.png`、`classroom-student-route.png`，以及`home-design-browser.log`和`home-design-classroom.log`。

测试命令：`npm run qa:home`。所有展示数据来自现有课程和学情；评分与课堂服务逻辑未改动。
