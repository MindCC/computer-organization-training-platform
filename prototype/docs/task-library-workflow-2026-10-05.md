# 任务库与工作流编排

用户要求：单独创建任务；已有任务收进任务库，支持新增、查看、修改、删除与发布；编排使用可拖动的工作流节点，支持自定义节点。保留学生直接查看与教师演示、进度反馈。

## 实现约定

- 教师工作区分任务库、课堂执行、教学活动和学情统计。任务库默认展示列表、搜索和创建入口，创建/编辑进入独立编辑页面。
- 任务库由教师持有，服务端保存版本。已有课堂的任务内容作为可复用副本导入；课堂与学生记录保留。库中删除仅隐藏模板。
- 发布选择教师自己的班级，以保存版本生成独立课堂快照并开始课堂；重复请求幂等，开课冲突回滚。历史课堂不会随库中编辑或删除而改变。
- 工作流保留顺序任务语义。节点支持拖动、平移、缩放、选择、连线调整顺序、添加/删除、快捷上下移动；保存位置和顺序，学生按箭头顺序完成。
- 自定义节点允许填写名称、教学要求、时间，选择本人确认或提交文字说明。属于参与记录，不自动判定知识成绩，不自动发送给 AI。
- AI 创建、现有功能资源、教师预览/大屏、课堂生命周期和反馈继续使用。
