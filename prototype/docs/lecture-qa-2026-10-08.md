# GKK 讲演接入平台小芯答疑

用户选择方案三：讲演保留 GKK iframe，问答改用平台现有小芯与平台账号，学生无需另登 GKK。

## 已实现

- 播放器旁新增“本课答疑”，桌面默认展开；可收起恢复完整讲演区域。窄屏在讲演与问答之间切换，全屏包含问答区。切换/全屏均保留原 iframe，未重新加载第三方讲演。
- 使用现有 `/api/student/study-assistant`，教师通过既有角色映射使用 `/api/teacher/study-assistant`。保留平台登录、课程范围双重审核、每人并发/频率限制与学生对话留存，不要求 GKK 登录或凭证。
- 客户端只提交章节 ID、目录序号及本次主动问题。服务端从 `COURSEWARE` 重建讲演标题、章节大纲、目标、要点和本章全部知识点，避免此前只发前四个知识点的限制。拒绝不存在或非整数的讲演序号，忽略客户端伪造的标题、URL、令牌及成绩等额外字段。
- 支持选填“补充课件原文”：粘贴至多 6000 字并勾选后才发送；未勾选时不发送。服务端要求独立的 `materialConsent:'lecture-excerpt'`。补充文字作为引用数据处理，不能改变课程规则；未自动读取个人知识库或学习记录。
- 回答显示 AI/本地参考来源，并附本课大纲与知识点的“回答依据”；实际使用了补充文字的模型回复标出该节选。学生记录仍归个人账户，其他学生无权读取；教师试练不计学生成绩。
- 切换讲演或账户会卸载旧问答表单，旧异步回复不能写入新面板；失败保留问题供重试。展开答疑时隐藏重复的悬浮小芯，收起后恢复。
- 帮助指南已更新，新增 `npm run qa:lecture-qa`。

## 当前资料范围

仓库中有课程大纲与知识点，没有这些 GKK 讲演的逐页 PPT/讲稿原文或播放页接口。因此默认回答依据是平台课程资料，不声称已读取 GKK 当前页，不控制第三方数字人的暂停/发声。若问题针对具体公式或例题，可在面板补充相应原文。此次没有新增原始 PPT 上传入口或共享课件发布流程。

问答沿用现有 `STUDY_ASSISTANT_*` / 既有兼容配置；没有新建模型账户、变更凭证或接入第三方 GKK 身份。生产模型可用性仍取决于运行服务配置。
