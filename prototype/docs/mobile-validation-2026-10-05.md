# 移动端展示验收（2026-10-05）

## 环境与结果

生产构建、独立临时数据库、单个无头 Edge 浏览器；启用触屏与移动视口模拟。检查 320×844、360×844、390×844、768×1024 与 844×390。`npm run qa:mobile` 结果为 229 项通过、0 项失败，无未捕获页面异常。首屏静态 JavaScript 为 496,598 字节，低于 512,000 字节门禁。

## 覆盖

- 学生与教师登录、顶栏滚动导航、个人设置保存、帮助和通知弹窗。
- 教师手动/AI 编排入口、学情洞察、学生表、装机练习、助教报告与证据、采纳并修改教学安排、创建草稿、课堂演示与大屏模式、开始课堂、教师学习记录。
- 学生接受课堂任务、随堂题目与刷新恢复、课堂导航、普通课程地图、学习记录和错题本（空数据及演示数据）、课后作业、AI 助教弹窗、演示章节入口、AI 课件播放器与全屏、知识库、思维画板空态和本地生成后的画布、硬件挑战入口、3D 部件探索与实际下一步操作。
- 页面横向溢出、阶段卡片文字对比度、3D 步骤按钮触控宽度，以及部件列表、步骤控制与架构图的遮挡检查；截图人工复核。

## 修复

1. 手机首页新手引导标题与“跳过引导”按钮换行，消除页面横向溢出。
2. 课堂容器使用可收缩的网格列，课堂控制按钮换行，任务链阶段列表在容器内部滚动。
3. 已采纳的教学安排默认展开，便于教师直接修改。
4. 阶段卡片与演示按钮明确设置文字颜色，避免继承深色仪表板的浅色字。
5. 窄屏 3D 模式按钮与步骤按钮重新排列，步骤编号独占一行；增加场景高度，给部件列表、控制区和架构图各自留出空间。
