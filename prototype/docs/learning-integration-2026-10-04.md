# 错题、作业与课堂演示系统联动

## 已实现

- 错题本统一实验室失败、按章题库练习和已判分的教师课后作业，保留历史实验记录。
- 按章题库提交由服务端使用课程题库重新判分；结果存入当前账号，刷新或换设备可继续。草稿和结果缓存使用按账号隔离的 v2 存储键。
- 筛选来源及待巩固状态；题库错题直接定位到该章的单题重练，答对标记已订正，再次答错恢复待巩固。
- 作业错题展示原答、参考答案、解析、教师反馈及指定原题回看。客观题可以就地订正，原作业答案、成绩与状态保持不变；简答题在教师判分后收录，并通过教师反馈复习。
- 草稿、空白答案及未批改简答题不收录；提交标识支持丢失响应后的幂等重试，跨账号读取和订正受服务端鉴权约束。
- 九个课堂演示和演讲课件使用实际平台顶栏、身份菜单和返回入口；演示可转到本章题库，教师可回到教师看板。
- 开发、预览与生产共用演示链接白名单：公开原链接转到 `/?demo=...`，内部 iframe 用 `?embedded=1` 读取原始 HTML。原教材算法、互动控件及平台成绩联动脚本没有改动。

## 数据边界

原来共享的 `zcyl:chapter-practice-v1` 本机缓存没有账号归属。保留原键，不自动把它导入当前学生，避免把上一位机房用户的答案和成绩混入新账号；从本版提交的题库成绩自动同步和收录。
