# 装机店新玩法：诊断与定向升级

## 入口和完成内容

硬件配置挑战 → “进入维修与升级工单”。统一平台顶栏保留，页内可返回装机店；维修委托板选择客户。旧六张装机订单及成绩保留。

| 客户 | 症状 | 旧机瓶颈 | 可行升级 | 新购费用 | 同任务模拟耗时 |
| --- | --- | --- | --- | ---: | --- |
| 小周 | IDE、浏览器和虚拟机一起开时卡顿 | 8GB 内存装不下 14GB 工作集 | 16GB 内存套装 | ¥320 / 420 | 76.7s → 28.7s |
| 小许 | 近 800GB 素材库加载慢 | 1TB 机械硬盘 | 保留容量，升级 1TB SSD | ¥620 / 700 | 61.7s → 34.5s |
| 阿澄 | 固定 CPU 编码导出慢 | 入门 CPU | 主流 CPU | ¥1150 / 1300 | 67.5s → 49.2s |

玩家接待并追问 → 三项基线检测 → 证据诊断 → 预装旧机的真实 3D 拆换 → 接线、自检 → 相同三项复测 → 服务端验收 → 下一位客户。错误诊断可继续修正；不达标配置可继续拆换和复测。

## 模型与验收规则

这些数字是**教学模拟**，不对应具体品牌实际跑分。CPU、磁盘显示串行任务耗时份额，内存显示工作集占物理内存比例。共享模型：CPU 耗时＝计算工作量 / 教学性能系数；I/O 耗时＝加载工作量 / 存储系数；任务工作集超过内存后，每超过 1GB 增加 8 秒换页等待。实际客户任务的 I/O 工作量乘 0.8，独立加载检测使用固定工作量。所有复测保留与基线相同参数。显卡不参与这些固定 CPU / I/O 工作负载。

购件费用仅计算与旧机配置不同的新元件，不计算整机成本、旧件折价或服务利润。资料已经备份，硬盘更换后恢复资料；没有模拟真实文件复制或系统安装。

服务器检查三项基线、正确诊断、完整安装/接线证据、当前型号对应的三项复测、客户耗时阈值、容量与预算。通过得分从 100 起，每次错误诊断扣 5 分，每项额外更换非瓶颈元件扣 10 分，最低 60；验收失败记 0，仍可调整再验收。客户端传入的 score、passed 或测试指标不能改变结果。3D 开机过程由浏览器执行，服务端校验提交的结构证据，不能远程证明真实物理电脑已开机。

## 保存与联动

- 工单、检测、诊断、回执按学生账户保存；每次写入有版本和操作标识，相同操作重试返回已有结果，窗口间冲突要求重新载入。
- 响应丢失后提供“重试上次操作”；未确认的操作阻止发出不同操作。刷新可恢复服务器进度和本机装配草稿，开机状态不恢复。
- 维修独立出现在学习记录、学生 Markdown 报告、教师班级内学生详情；诊断错误联动统一错题本，验收成功标为订正，支持直达同类工单重做。
- 记录支持分批展开。每账户最多 300 张工单，每单最多 300 次写操作；重复请求不消耗操作次数。
