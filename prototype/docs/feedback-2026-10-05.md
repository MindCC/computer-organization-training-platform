# Trial feedback

User request: add feedback to the shared top-right navigation so trial users can suggest changes; only admin/admin123 can view submissions.

## Implementation

- Guests, students and teachers submit a category, up to 5000 characters, optional contact details and the current platform page label. The client never receives another user's feedback.
- SQLite stores submissions in `feedback`; `GET /api/admin/feedback` requires the authenticated `admin` role and returns paginated results with `Cache-Control: no-store`.
- The server provisions the `admin` account once with an scrypt password hash. Restarting preserves its password. No administrator demo login is provided.
- Legacy account role constraints are migrated transactionally, preserving IDs, foreign-key references, indexes, triggers and the autoincrement sequence. Existing teaching permissions remain role-specific.
- The administrator tab on the login form opens the inbox after authentication. The shared 反馈 action reopens it; ordinary accounts only see the submission form.
- The dialog includes loading, error, empty, submission-success and pagination states, focus containment, Escape/close behavior and mobile sizing. Feedback is rendered as plain text.
