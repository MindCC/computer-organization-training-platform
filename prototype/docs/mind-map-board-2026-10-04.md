# 思维画板

入口：学生和教师顶部「知识库」→ 左侧工具栏「思维画板」或侧栏「画板」。文档阅读区的「从此文档生成导图」会将前 6000 字填入素材框，等待用户主动生成。

- 文字：输入主题、自然语言需求或缩进提纲。配置了 AI 时请求结构化知识导图，未配置时仅按缩进／句子整理并标明本地来源。
- 图片：选择或拖入 PNG、JPEG、WebP（最多 5MB），预览后主动生成。要求支持 OpenAI 兼容 Chat Completions `image_url` 的视觉模型。模糊文字要求模型标注待核对，仍须人工核对。
- 编辑：点击或用下拉框选节点，改文字／颜色／12–24px 字号、所属分支；添加子节点；删除节点会同时移除后代和相关箭头。连接点可拖出关系箭头，也可用关系编辑器新增、修改或删除。允许多对多额外关系，层级树不能成环。
- 画布：React Flow 拖动、平移、滚轮／双指缩放，旁侧缩放／适应按钮，自动布局。最多 80 节点、8 层、120 条额外关系。
- 重绘：只发送当前导图和固定的梳理要求，合并重复内容、按主题分组。无 AI 时仅重排与配色，界面明确说明。
- 保存：手动保存到 SQLite，按账号隔离，版本冲突返回 409 并提示另存为；未保存修改保留在账号对应的本机草稿中。草稿恢复不代表云端保存。生成失败、保存失败保留当前内容。
- 导出：PNG 和 SVG 包含全部节点、层级与关系箭头，独立于当前缩放／视窗；SVG 文本转义，PNG 限制输出尺寸与像素数以控制内存。

## 配置

文字默认使用现有 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`。图片识别独立配置：

```text
MINDMAP_API_KEY=<视觉模型服务密钥>
MINDMAP_BASE_URL=<含 /v1 等接口前缀、不含 /chat/completions 的地址>
MINDMAP_MODEL=<支持 image_url 和 JSON 输出的模型名称>
MINDMAP_VISION_ENABLED=1
MINDMAP_TIMEOUT_MS=45000
```

配置仅放在服务端环境变量中，前端读取能力布尔值，不接触密钥。只有用户主动勾选并生成时发送所选素材／当前导图；服务端按白名单构建请求，不附带身份、成绩、教师评语、历史作答或其他文档。截图中的豆包型号是功能参考，不是此项目的固定模型依赖。

## 验证

```text
node --test src/mindMap.test.mjs server/mindMapGeneration.test.mjs server/mindMapRoutes.test.mjs
node scripts/run-browser-qa.mjs scripts/verify-mind-map.mjs --production --seed-demo
```

浏览器验收在临时数据库运行，视觉部分使用明确的测试响应，不调用外部 AI；服务端测试验证真实 HTTP 接收、视觉请求结构、超 1MB 图片、鉴权、账号隔离、版本冲突和错误保留。真实视觉模型效果须配置后用用户选定的图片验收。

2026-10-04 验证结果：全量测试 586 项通过；随后数值提纲与帮助／教师刷新调整的定向 22 项通过；生产构建、入口脚本预算（486773 字节，小于 500 KiB）和生产浏览器验收通过。使用现有文本 AI 的公开 Cache 主题真实生成验证通过，返回 12 个节点与 10 条关系；环境中尚无独立视觉模型配置。截图及导出文件保存在 `qa-artifacts/mind-map-*`。
