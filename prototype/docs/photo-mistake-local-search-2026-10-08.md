# 拍照错题解答优先本地检索

点击“讲错因”先检索当前账号的知识库原文及已有课程题库答案。检索使用 SQLite FTS5 和本地题目匹配，不调用任何模型，不消耗模型 Token。命中后直接展示参考答案、已有解析和文档名称/页码，并标明“知识库命中 · 本次未调用 AI（0 Token）”。本地资料不会被包装成针对学生作答生成的错因诊断。

如果未找到同题答案，先复用该错题已缓存的 AI 讲解；没有缓存才展示 AI 同意选项。用户勾选并点击生成后，服务端会再次检查本地答案/缓存，仍未命中才调用模型。

匹配范围与限制：

- 知识库只查询当前登录账号的文档；教师题库也仅限该账号自己的题目，不读取其他教师的未发布内容。
- 原文需要包含完整题干和明确的“答案/参考答案/正确答案/解答”字段；可读取相邻块，支持题目和答案分处两个文本块的情况。
- 题干只规整空白和末尾问号/句号。数值、正负号、小数点、运算符、阶乘符号和符号大小写均保留；选择题还要求选项及其顺序匹配。仅章节或知识点相关时，仍视为没有找到同题答案。
- 本地命中附带出处供核对，资料本身的正确性仍以原文为准。无明确答案、结构不完整或题干未能精确匹配时进入未命中流程。
- 检索到的私有文档原文不会自动附加到外部 AI 请求。当前规则用于拍照错题讲解，未改动其他助教问答、视觉识别、同类题生成或简答判分。

验证：全量 `npm test` 789 项通过；新增知识库行为测试覆盖账号隔离、跨块答案、数值/符号差异、题库复用和选择题匹配。学生/教师真实 HTTP 路径通过。生产构建、原有 7 步拍照错题浏览器验收、新增本地命中及原修复浏览器回归均通过；入口 JavaScript 510111 字节，满足 512000 字节预算。

测试使用隔离内存数据库和单个无头 Chromium，模型由测试替身响应，未发送真实学生数据。改动尚未提交、推送或部署。
