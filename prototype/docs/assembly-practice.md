# 装机教学练习

入口：硬件配置挑战 → **进入装机教学练习**。练习沿用当前选择的硬件型号，使用独立装配状态；客户订单的配置、装配草稿和成绩不受影响。

## 三种模式

| 模式 | 目标 | 提示方式 |
|---|---|---|
| 引导练习 | 从空机箱开始，完成部件安装、散热、接线和开机 | 根据当前装配状态显示下一步、目标和原因；保留预览与匹配颜色 |
| 独立练习 | 自行判断安装顺序、插槽和接口 | 默认隐藏匹配预览、正确插槽高亮和缺项清单；可主动查看提示 |
| 故障练习 | 根据症状排查一台已预装的主机 | CPU 供电、散热组件、SATA 数据三类工单；默认隐藏匹配提示，尝试自检会反馈故障阶段 |

3D 场景支持拾取、安装及接口接线。独立/故障模式也提供辅助操作：选择部件 → 手动选择安装目标 → 安装所选部件；线缆端和目标接口需要自行配对。没有 WebGL 时仍可使用辅助操作。

引导与独立练习均从未装配状态开始。故障模式使用真实装配数据构造缺件或缺线状态，修复后仍需执行开机自检，不能通过选择一个答案直接完成。

## 故障工单（教师参考）

- 工单 A：缺少 CPU 8-pin 供电；处理器初始化检查不通过。接通电源 CPU 8-pin 到主板 CPU 供电接口。
- 工单 B：未安装 CPU 散热器，风扇连接缺失；散热检查不通过。固定散热器并接通 CPU_FAN。
- 工单 C：缺少 SATA 数据线；存储识别检查不通过。连接 SSD 数据口和主板 SATA 口。

同时保留其他装配约束。学生若拆掉其他必要部件，即使修复工单原故障，也必须重新补齐才能通过自检。

## 复盘与计分

成功开机后本轮锁定，展示练习分、错误次数、主动提示次数、完成用时、错误记录与改进建议。100 分起，失败操作每次扣 5 分，主动提示每次扣 3 分，最低 0 分。引导中自动显示的步骤不扣分；只有主动点击“查看提示”记一次帮助。

这是教学练习指标，不写入订单成绩或课程正式成绩。未完成时不显示成功分数。完成后可观察模型，点击“重新练习”开始新一轮。

切换模式、切换工单、重新练习会新建练习会话。返回订单、离开页面或刷新后，本次练习记录不保留；订单草稿仍按已有学生/订单规则恢复，并要求重新开机自检。

## 验证入口

- `node --test src/assemblyPractice.test.mjs`：故障状态、修复约束、引导前置条件、核显/独显和复盘计分。
- `npm run qa:production`：原有生产 3D 流程，加三种练习、全部故障修复、提示隐藏/恢复、复盘、重练、移动布局和订单草稿隔离。
- `node scripts/run-browser-qa.mjs scripts/verify-performance.mjs --production`：开机动画帧率、原装配生命周期及十次进入练习/切换故障/返回订单的资源增长。

基于 `afaa737` 的本轮实现，在 Windows 本机单个无头 Chromium 中验证：

- 自动测试 357/357 通过，覆盖三类故障、缺失其他必要部件、核显/独显、计分下限和完成记录锁定。
- `qa:production` 通过：生产模块导入、原有 32/32 3D 检查，以及引导完整装配、独立错误尝试/求助/完成、全部故障修复、复盘、重练、刷新、移动端及订单草稿逐项对比。
- 十次进入练习、切换故障、返回订单后 JS 堆增长 3,462,732 字节，处于项目既定预算内；无页面脚本错误。
- 开机装配场景约 60.26 FPS，P95 帧间隔 16.7 ms，十次装配进出后 JS 堆增长 1,391,276 字节。
- 首屏、3D 包、图片预算通过；3D 增量 gzip 约 196 KB，模型资产未改动。
- 桌面与窄屏截图已复查，产物和日志保存在忽略目录 `qa-artifacts/assembly-practice-*`。

性能数据是本机测量，不代替教室集显设备抽测；JS 堆不等同于 GPU 显存。本轮没有变更正式课程成绩、订单提交接口或教师课堂流程。
