# 装机教学练习

入口：硬件配置挑战 → **进入装机教学练习**。练习沿用当前选择的硬件型号，使用独立装配状态；客户订单的配置、装配草稿和成绩不受影响。

## 三种模式

| 模式 | 目标 | 提示方式 |
|---|---|---|
| 引导练习 | 从空机箱开始，完成部件安装、散热、接线和开机 | 根据当前装配状态显示下一步、目标和原因；保留预览与匹配颜色 |
| 独立练习 | 自行判断安装顺序、插槽和接口 | 默认隐藏匹配预览、正确插槽高亮和缺项清单；可主动查看提示 |
| 故障练习 | 根据症状排查一台已预装的主机 | CPU 供电、散热组件、SATA 数据三类工单；默认隐藏匹配提示，尝试自检会反馈故障阶段 |

3D 场景支持拾取、安装及接口接线。独立/故障模式也提供辅助操作：选择部件 → 手动选择安装目标 → 安装所选部件；线缆端和目标接口需要自行配对。没有 WebGL 时仍可使用辅助操作。

引导与独立练习均从未装配状态开始。故障模式使用真实装配数据构造缺件或缺线状态，修复后仍需执行开机自检，不能通过选择一个答案直接完成。

## 故障工单（教师参考）

- 工单 A：缺少 CPU 8-pin 供电；处理器初始化检查不通过。接通电源 CPU 8-pin 到主板 CPU 供电接口。
- 工单 B：未安装 CPU 散热器，风扇连接缺失；散热检查不通过。固定散热器并接通 CPU_FAN。
- 工单 C：缺少 SATA 数据线；存储识别检查不通过。连接 SSD 数据口和主板 SATA 口。

同时保留其他装配约束。学生若拆掉其他必要部件，即使修复工单原故障，也必须重新补齐才能通过自检。

## 复盘与计分

成功开机后本轮锁定，展示练习分、错误次数、主动提示次数、完成用时、错误记录与改进建议。100 分起，失败操作每次扣 5 分，主动提示每次扣 3 分，最低 0 分。引导中自动显示的步骤不扣分；只有主动点击“查看提示”记一次帮助。

这是教学练习指标，不写入订单成绩或课程正式成绩。未完成时不显示成功分数。完成后可观察模型，点击“重新练习”开始新一轮。

切换模式、切换工单、重新练习会新建练习会话；已完成的历史复盘保留。返回订单、离开页面或刷新后，再进入练习会恢复最近一次未完成会话，包括模式、故障工单、硬件型号、已装部件、结构/线缆、当前部件以及错误与主动提示记录。恢复后必须重新开机自检；离开页面到重新进入之间的时间不计入恢复后的累计用时。

## 保存、同步与历史

记录按当前登录学生和客户订单隔离，本机副本保存在 `zcyl:assembly-practice:v1:` 命名空间；服务器副本保存在现有 SQLite 数据库。页面显示“已同步到服务器”后，可在同一平台的其他设备登录同一账号，选择同一订单并进入练习，恢复未完成进度和历史。恢复后仍需重新开机自检。

首次进入先读取服务器；旧版本本机记录也会迁移。如果本机和服务器都有不同进度，会出现冲突选择，避免静默覆盖。选择“恢复服务器进度”或“使用本机进度并同步”后，两侧历史按练习会话 ID 去重合并，最多保留最近 20 次；未完成进度使用所选副本。其他设备再次修改时仍会重新检查版本。冲突处理期间暂停练习操作。

每次操作先更新本机副本，连续操作合并后约 1 秒发起同步；联网、页面重新可见或可见页面每 15 秒会重试。断网时仍可练习，待发送请求连同本机文档保存；刷新后继续使用同一个请求标识重试。已经到达服务器但响应丢失的保存不会重复增加记录。登录失效、服务器拒绝或本机存储不可用会单独提示，也可手动重试。

只有已同步的内容能从其他设备恢复；离线时清除浏览器数据会丢失尚未上传的内容。本轮不提供离线页面安装，完全断网时刷新页面能否打开仍取决于页面缓存。教师看板尚未接入，服务器保存的练习分与完成结果属于学生练习记录，不是正式成绩或服务端重新判分的证据。

操作和记录变化后自动保存，并每 15 秒、页面离开/隐藏时补存累计用时。当前练习和历史使用一个版本化记录保存，避免更新其中一部分后产生不一致。硬件配置、节点状态和记录形状在读写时重新验证；损坏或未知版本数据回退到新练习。

完成结果保存最近 20 次，按稳定会话 ID 去重。历史区域可展开查看模式/工单、时间、练习分、错误次数、提示次数、用时与改进建议；每次历史记录展示最近 20 条失败操作。查看历史不会恢复当前开机成功或正式成绩。完成后的再次进入从新一轮开始，已有完成结果留在历史列表。

浏览器禁止写入或存储配额不足时，页面会显示“无法保存练习”，仍可继续本次内存练习并尝试服务器同步；失败写入不会覆盖此前保存的有效本机记录。此时不要在离线状态下关闭页面。

## 同步接口与运维

- `GET /api/student/assembly-practice/:caseId` 返回 `{ revision, updatedAt, document }`；无记录返回版本 0 和空文档。
- `PUT` 同路径接收 `{ operationId, baseRevision, document }`，返回新版本和 `duplicate` 标记。旧版本或复用标识提交不同内容返回 409，包含 `current` 服务器副本。文档校验、保存及去重在数据库事务内完成。
- 身份来自现有登录会话，只允许学生访问自己的记录。浏览器额外发送 `x-practice-student` 防止页面打开期间切换账号后误存；不接受请求体指定存储学生。订单必须存在于教学订单目录，沿用全局跨站请求检查。
- 文档版本为 1，最多 20 条历史、每轮最多 5000 条事件；服务端文档上限 900000 字节，超过时保留本机并显示拒绝状态。恢复与 API 入库都清除未知字段及开机成功标记，历史分数按练习规则重新计算。
- 启动服务时现有幂等迁移自动创建 `assembly_practice_documents` 和 `assembly_practice_operations` 表；每学生/订单最多保留最近 200 个同步回执。更早重试仍受版本校验保护，可能要求人工解决冲突。部署此功能需同时更新前后端，数据库备份仍沿用现有流程。

## 验证入口

- `node --test src/assemblyPractice.test.mjs`：故障状态、修复约束、引导前置条件、核显/独显和复盘计分。
- `node --test src/assemblyPracticeStorage.test.mjs`：学生/订单隔离、配置与装配恢复、离线时间、清除开机标记、历史去重与保留上限、损坏数据和写入失败。
- `node --test src/assemblyPracticeSync.test.mjs server/assemblyPracticeRepository.test.mjs server/assemblyPracticeRoutes.test.mjs`：同步队列、断网/响应丢失、并发冲突、身份隔离及 HTTP 数据校验。
- `npm run qa:production`：原有生产 3D 流程，加三种练习、全部故障修复、提示隐藏/恢复、复盘、重练、移动布局和订单草稿隔离。
- `node scripts/run-browser-qa.mjs scripts/verify-performance.mjs --production`：开机动画帧率、原装配生命周期及十次进入练习/切换故障/返回订单的资源增长。
