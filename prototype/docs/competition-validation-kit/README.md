# 真实试教与独立评测采集包

这些CSV只有字段头，没有造出的案例、成绩或教师审核。正式采集后才能形成参赛证据。

## 1. 一班两次教学活动

教师选择已有评价题、不同题号的复测与明确知识目标。保留任务版本、课堂ID、节点ID、原题与复测题；系统的教学诊断/复测和建议来源页面提供相应线索。

填写`classroom-trial.csv`：每名学生每次评价每题一行，`participant_code`用匿名代号；`phase`为diagnosis、retest或delayed_retest；`correct`填0/1，`hint_level`填0～4。尚无证据填空，不填0。`repeated_question`填true/false，区分同题重复与变式。

指标：同一学生、知识点的题目正确率；完成复测人数/接受任务人数；不同提示层级的分布；延迟复测和同类错误复现。前后题目难度和提示条件不同要说明；少量试用不能单凭前后分数声称因果提升。

## 2. 教师工时与学生体验

`teacher-time.csv`按实际活动记录准备、监控、讲评和补学安排的分钟数；`method`为原有方式或本系统。相同内容、班额和记录范围才适合比较。平台番茄钟、服务器墙钟时长不能代替教师工时或注意力观测。

`student-feedback.csv`记录三项1～5分反馈及开放意见。反馈用于可用性判断，不等同于知识掌握。

## 3. 教师审核的模型独立评测

先整理30～50个多样案例：求和/进位/公共结构错误、等价正确电路、未知信号及歧义解释。`case-review.csv`保存教师审核后的预期事实、可接受依据与帮助层级；选定独立测试案例后，不用测试标签修改提示或规则。

将同一案例分别交给local_rule、ordinary_qa、tool_coach，保存输出，再填写`model-review.csv`。人工核查检测事实、引用是否支持解释、建议可操作性、是否提前给答案，以及错误回退。真实学生材料不直接发送模型；现有助教只接受明确选中的受限诊断，首次比较可使用公开合成输入。

指标分别按已审核、可评价样本计算：事实正确率、引用支持率、可执行建议比例、答案泄漏次数、合法工具调用比例、回退率。不可评价项标NA并单列数量，不进入分母。有效引用ID与文字语义支持分开评价。

## 4. 参赛证据整理

同一匿名案例串联：课堂目标 → 提交 → 诊断 → 教师修改/说明 → 发布版本 → 补学 → 复测。教师界面的原始报告和调整记录可用于内部核对；参赛截图和录屏另用匿名账号，并检查教师输入自由文字是否含身份。

发布材料中分别标明工程验收、合成评测和真实试教；记录版本、人数、课次、题目条件及缺失样本。此目录提供采集工具，不表示已经完成试教或独立评测。
