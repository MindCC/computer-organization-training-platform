# 学习树优化 · 2026-10-03

## 反馈与改动

用户反馈学习树不好看。实际页面中，长枝条把树冠拉偏；全部实验标题随 SVG 缩小后很难读，右侧统计栏还把画布撑得过高。

- 保留真实树形，八章从下向上交替分枝；密集章节使用两排细枝，36 个真实实验各占一片叶子，布局不受成绩改变而跳动。
- 加粗并柔化树干，用棕色枝干、带叶脉的绿 / 琥珀 / 灰绿叶片替换圆点；停止无限脉冲。
- 树冠两侧的章节标签使用固定字号，避免压住叶子。详细实验名称、状态和成绩放在同区的章节列表，参与型不显示 0 分。
- 支持章节选择、放大本章、复位、滚轮缩放、拖动平移；叶子和列表点击均进入原实验，叶子也支持 Enter / 空格。
- 缩放控件位于树旁；窗口变化时自动重适配，手动平移或缩放后不会随意重置。指针取消和卸载会清理监听，不捕获指针。
- 统计图移到树下方，保留放大图、星图、演示练习和章节明细。星图计数由当前课程计算为 30。
- 平板与手机将章节列表放在树下方并完整展示；修复记录页负边距导致的横向溢出。
