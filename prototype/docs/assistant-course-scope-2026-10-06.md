# 助教课程范围限制 — 2026-10-06

## 执行链路

服务端对学生与教师个人试练的 study-assistant 请求执行同一规则：

1. 先校验身份、每次发送同意、问题长度和课程上下文；题目/概念ID必须来自真实课程目录。
2. 规范化全角与零宽字符，直接拦截明显的忽略规则、改变角色和无关/混合任务请求。
3. 配置了AI时，独立分类请求只判断课程范围；只有严格的 `{"decision":"course"}` 才进入答疑生成。CPU等关键词、章节标题和合法题目上下文不能替无关请求获得许可。
4. 生成回答通过原有结构校验后，再检查解释、每一条步骤和自测问题。明确无关任务由规则拦截，其余需独立语义复核；只有整个回答通过才能以AI回答展示。
5. 未知、异常、格式错误或超时不放行未经检查的输出，返回课程引导或可信本地课程参考。前端将“课程范围提示”与API不可用区分。

允许范围包括八章计算机组成原理、公开题目讲解、硬件选型、模拟装机/供电接线、数字电路实验及直接服务于课程概念的简短类比。未指定主题且未关联实际题目/实验的泛问会要求补充信息；不因关键词不足直接拒绝罕见课程术语或英文课程问题。

分类器只收到主动输入问题及公开题目/概念标题/实验类别。只有学生本次明确选择的装机/电路快照进入答疑；身份、成绩、历史、私有教师反馈仍不自动发送。主请求保留每分钟10次/同账号单请求并发限制。整个AI链路预算不超过22秒，分别限制输入审核、生成和输出审核。
