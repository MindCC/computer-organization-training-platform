# 拍照错题审查问题修复（2026-10-08）

1. 核对保存路由增加有大小限制的 JSON 解析，学生和教师试练均可保存后归档；保留缺少章节的归档门禁。
2. 作答表单按轮次 ID 独立挂载，切换轮次清空输入；旧轮次的异步判分结果不覆盖当前轮次。
3. 根据尚未自评的简答题显示 AI 同意框，并提交该同意；待判简答未自评、也未同意时禁用提交。服务端只发送待判题目。
4. 增加账号隔离的服务端草稿列表，在拍照导入对话框提供“继续核对”和“保存草稿并关闭”。关闭、刷新后无需重新识别；已归档内容不出现在草稿列表。
5. 同类题只发送题干（含选项）、题型和章节/知识点，不发送原作答或参考答案。错因讲解仍按用户同意发送原作答。
6. 当前单进程服务共享数据库句柄，按账号和提交标识串行化识别、出题，按账号和错题 ID 串行化讲解；等待后重新读取落库结果，避免重复模型调用与唯一约束冲突。失败释放等待队列，可继续重试；识别及题目入库在同一事务中完成。前端失败重试保留提交标识，照片变更时生成新标识。若未来改为多进程服务，需将进程内等待队列升级为共享任务锁。
7. 只有复习卷打印节点存在时，打印样式才隐藏应用；关闭预览后普通打印恢复。
8. 自动掌握只更新未掌握条目，保留已有的手动掌握来源；手动取消后，新练习仍可自动掌握。
