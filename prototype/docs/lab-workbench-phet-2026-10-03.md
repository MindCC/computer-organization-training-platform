# 电路实验工作台调整

## 追加：统一平台顶栏（2026-10-03）

- 根据机器数实验截图反馈，电路实验与计算机组成探索复用 `App.jsx` 的平台顶栏，与硬件装机页共享 Logo、主导航、通知和头像菜单；个人设置继续使用同一弹窗。
- 当前实验、章节顺序编号、状态和计分方式放入顶栏下方的浅色信息条。主导航在不超过 1200px 时换为第二行；Logo 限定在自己的按钮内，避免透明图片覆盖导航点击。
- 挑战路径依据实际顶栏高度吸顶。3D 探索按顶栏后的剩余高度布局，课堂 HUD/暂停容器也保留可伸展区域。
- 生产浏览器专项增加共享顶栏一致性、头像菜单、主导航从实验切换到装机/课程首页、机器数截图和 3D 画布高度检查。最终证据：`qa-artifacts/lab-topbar-after.log`、`lab-machine-shared-topbar.png`、`hardware-shared-topbar.png`、`lab-overview-shared-topbar.png`。原有完整 3D 回归 32/32 通过，记录 `qa-artifacts/lab-topbar-3d.log`。
- 生产构建成功；初始 JS 468117B / 512000B，增量 3D gzip 198794B / 225280B。工作树包含此前装机店、AI 客户与 PhET 改动，未替换其功能逻辑。

## 依据

- 用户反馈（2026-10-03）：实验页被强制限制在一屏，工作台看不到；希望参考 PhET 并改善元件外观。
- 参考：[PhET 关于直接操作、布局与即时反馈的研究](https://phet.colorado.edu/publications/archive/PhET%20Interview%20Paper%20Part%20II.htm)。借鉴交互原则，使用本项目自有组件和原有仿真逻辑。

## 实现

1. 删除固定工作区高度和隐藏溢出的规则；画布独立保持至少 400px 高度，说明区在下方自然滚动。
2. 精简重复标题和工具按钮，把属性、学习状态与 AI 助教收进可展开的观察区。
3. 提供放大工作台和 Esc 返回；保留当前连线、输入、用例和视图设置。放大层低于课堂暂停与评测结算层，键盘焦点留在工作台内。
4. 输入使用可点击/键盘操作的开关，输出使用真实信号驱动的灯，逻辑门使用标准形状。统一浅色模块、清楚端口和信号配色。
5. 支持显示/隐藏端口名称和信号数值。手动探测显示实际输入和输出，切换一个开关时保留其他输入的当前值。
6. 画布尺寸变化时自动适配全部元件；其他时候保留玩家的平移和缩放。固定实验和自由装配复用相同元件。
